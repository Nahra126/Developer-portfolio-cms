# Developer Portfolio CMS

A dynamic Portfolio Content Management System (CMS) built with Core PHP and MySQL.

## Project Overview

This project allows a developer to manage their portfolio through an admin panel without editing the source code.

## Technologies

- Core PHP
- MySQL
- HTML5
- Bootstrap 5
- JavaScript
- XAMPP

## Features

### Public Website

- Home
- About Me
- Skills
- Projects
- Certificates
- Contact
- Download CV

### Admin Panel

- Secure Login
- Dashboard
- Manage About
- Manage Skills
- Manage Projects
- Manage Certificates
- Manage Resume
- View Contact Messages
